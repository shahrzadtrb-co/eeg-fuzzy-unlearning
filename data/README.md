This project uses the public Complete EEG dataset hosted on Kaggle.

Source:
Aman Anand, Complete EEG dataset, Kaggle.
URL: https://www.kaggle.com/datasets/amananandrai/complete-eeg-dataset

How to use:

Download the dataset manually from the Kaggle page above.
Extract the files.
Place the EEG CSV files inside data/raw/.

Note:
The raw dataset files are not included in this repository. This repository only contains the notebook, paper, and project files needed to reproduce the analysis after the dataset is downloaded.

If you want to mention it in your main README, use this exact line:

Dataset source: Aman Anand, Complete EEG dataset, Kaggle, https://www.kaggle.com/datasets/amananandrai/complete-eeg-dataset

If you want to mention it inside the notebook, use this exact markdown line:

Data source: Aman Anand, Complete EEG dataset, Kaggle, https://www.kaggle.com/datasets/amananandrai/complete-eeg-dataset
