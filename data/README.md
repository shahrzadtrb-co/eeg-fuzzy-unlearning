# Data used in the project

This project uses the public Complete EEG dataset hosted on Kaggle.

Source:
Aman Anand, Complete EEG dataset, Kaggle.
URL: https://www.kaggle.com/datasets/amananandrai/complete-eeg-dataset

How to use:

1.Download the dataset manually from the Kaggle page above.	



2.Extract the files. 



3.Place the EEG CSV files inside data/raw/. 

Note:
The raw dataset files are not included in this repository. This repository only contains the notebook, paper, and project files needed to reproduce the analysis after the dataset is downloaded.
